# getokui — Web & Famous-Brand Benchmarks

A curated map of **world-class, well-designed sites** to reference alongside the
local 213-template DNA library. Two jobs:

1. **Current-year trend** — the local library is frozen at bundle time. The web
   tells you what great design looks like *right now* (search the current year).
2. **Named brand benchmarks** — real companies whose UI is a gold standard for a
   vertical. Use them as the taste bar: "make the CTA feel like Stripe's", "cards
   like Bank Jago's", "motion like Linear's".

## The hard rule — pattern, not property (read before using any of this)

You may study these sites and **adapt their design language, component patterns,
CTA style, spacing, and motion**. You may NOT copy, reproduce, or ship:
- their **logo, brand name, wordmark, or trademark**,
- their **copy / headlines / product names / testimonials**,
- their **photos, illustrations, icons, or other proprietary assets**.

Take the *shape and feel* (a pill CTA with a soft shadow and a hover-lift; a
bento feature grid; a glassy sticky nav) and **re-skin it to the user's palette
and content**. That's the difference between "designed like Gojek" (good) and
"a Gojek clone" (not ok). Same principle as the local DNA: **style & pattern in,
brand assets & content out.**

Web can't be pixel-rendered here (no renderer) — use it for **direction,
patterns, and named benchmarks**, and use the local **DNA files** for concrete,
legal-to-copy class strings + keyframes. Web layers on top; DNA is the anchor.

## How to search (current year)

Always include the current year so results are fresh (as of this writing, 2026):
- `"<vertical> landing page design <year>"` — e.g. "fintech landing page design 2026"
- `"best <vertical> website design <year>"`
- `site:awwwards.com <vertical>` / `site:godly.website <vertical>`
- `"<brand> website"` when you want one specific benchmark's current look

Prefer galleries and the brands' **own** marketing sites. Judge with getokui's
eyes: composition (not centered-slop), type scale, spacing rhythm, motion,
component polish — the same dimensions the DNA captures.

### Design galleries (best-of, curated)
- **Awwwards** (awwwards.com) — award-winning, cutting-edge motion & layout.
- **Dribbble** (dribbble.com) — huge concept/shot library; search by vertical +
  year (e.g. "umrah app 2026", "government portal", "school website"). Great for
  component & CTA ideas and fresh visual directions. Treat shots as *direction*
  (many are non-production mockups) — still pattern-not-property: adapt the idea,
  never lift a designer's exact assets/illustrations.
- **Godly** (godly.website) — modern, tasteful, current.
- **Land-book** (land-book.com) — landing pages, huge variety.
- **SiteInspire** (siteinspire.com) — clean, editorial.
- **Refero** (refero.design) / **Mobbin** (mobbin.com) — real product UI flows &
  components (great for CTA / form / dashboard patterns).
- **Lapa Ninja** (lapa.ninja) — landing pages by category.
- **Behance** (behance.net) — deeper case studies, full brand/UI systems.

## Named benchmarks by getokui category

Use these as the taste bar. Search the brand's current site when you want to see
its present-day execution. Adapt, never clone.

### fintech / saas-finance
- **Indonesia:** Bank Jago, Jenius (BTPN), Blu (BCA Digital), Flip, Amar Bank.
- **Payment gateway:** Xendit, Midtrans, DOKU, iPaymu, Faspay.
- **Global bar:** Stripe, Ramp, Mercury, Wise, Brex, Coinbase (crypto-finance).
- Feel: trust + precision. Clean grids, restrained palette + one confident
  accent, crisp Lucide-style icons, subtle depth, high-contrast CTAs.

### ai-saas / saas / dev-tools
- **Global bar:** Linear, Vercel, Framer, Raycast, Supabase, Retool, Resend,
  Clerk, Stripe (docs/dev). 
- **Indonesia:** Ruangguru (product), Mekari, Kata.ai.
- Feel: sharp, technical, dark-mode-friendly, gradient/glow accents, keyboard-y
  micro-interactions, monospace touches, bento feature grids.

### marketplace / super-app / e-commerce
- **Indonesia:** Tokopedia, Gojek, Grab, Shopee, Blibli, Bukalapak, Tiket.com.
- **Global bar:** Airbnb, Uber, DoorDash, Instacart.
- Feel: friendly, high-energy, rounded shapes, illustration-forward, bold
  category color, big tappable CTAs, playful motion.

### travel / hospitality
- **Indonesia:** Traveloka, Tiket.com, Pegipegi, tiket.com Hotels.
- **Global bar:** Airbnb, Booking, Airplane-era Expedia redesigns.
- Feel: photographic heroes, warm Solar icons, immersive full-bleed sections,
  clear search/booking widget as the hero focal point.

### hajj & umrah / religious travel
- **Indonesia:** Umroh.com, Tourindo/travel-umrah operators, big agents' sites;
  and the trust cues of Traveloka/Tiket applied to a pilgrimage context.
- **Reference feel:** calm, trustworthy, premium-but-warm. Deep greens / gold /
  cream palette, soft **Solar** icons, elegant serif or humanist sans for
  headings, Arabic-calligraphy-inspired accents (as *pattern/motif*, never a
  copied logo). Package cards (price + duration + hotel-star + departure date),
  clear trust signals (licenses/permits, testimonials, hotel proximity to
  Haram). Immersive photographic hero of Kaaba/Madinah — user's own licensed
  imagery, not scraped.
- Search Dribbble/Behance "umrah app 2026", "hajj booking UI" for current-year
  component direction.

### education / schools / campus / edtech
- **Indonesia:** Ruangguru, Zenius, Sekolah.mu, Quipper; university sites (UI,
  ITB, UGM) for institutional structure.
- **Global bar:** Duolingo, Khan Academy, Coursera, Notion-for-education.
- Feel: friendly + credible. Rounded shapes, approachable color, clear
  program/curriculum cards, enrollment CTA, stats (students, alumni, pass-rate),
  event/announcement sections. Solar or Lucide depending on playful vs
  institutional. For a school site: strong hero with the institution's identity,
  news/agenda grid, faculty/program sections, admissions CTA.

### government / public sector / civic
- **Indonesia:** as design *bar*, look at the cleaner national services —
  PeduliLindungi-era health UI, Jakarta Kini (JAKI), SatuSehat, Indonesia.go.id,
  Pajak/DJP redesigns. Global: **GOV.UK** (the gold standard for public-sector
  clarity & accessibility), U.S. Web Design System (USWDS), Singapore's
  gov.sg / LifeSG.
- Feel: **trust, clarity, accessibility first.** Restrained official palette
  (one strong institutional color + neutrals), high contrast, large legible
  type, obvious navigation, clear service/announcement cards, prominent search,
  plain-language CTAs. Lucide icons, generous spacing, no gimmicks — motion is
  subtle and purposeful. Accessibility (contrast, focus states, semantic
  structure) is part of the taste bar here, not optional.
- Pattern-not-property is doubly important: never reproduce an official seal,
  garuda, ministry logo, or coat of arms — use a neutral placeholder mark and
  let the user drop in their authorized emblem.

### telco / infrastructure / hosting
- **Indonesia:** Telkomsel, by.U, IndiHome, Niagahoster, Dewaweb, Biznet.
- **Global bar:** Cloudflare, Vercel, DigitalOcean.
- Feel: confident brand color, big type, clear plan/pricing tables, network/graph
  motifs, animated stats.

### crypto-web3
- **Global bar:** Coinbase, Phantom, Rainbow, Uniswap, Ledger.
- Feel: dark, neon/gradient, 3D or glow objects, animated gradients, glass.

### luxury / fashion / real-estate / architecture
- **Global bar:** Aesop, Apple, On Running, Zellige-era studios, Foster+Partners.
- Feel: editorial, huge display type, generous whitespace, restrained mono/duo
  palette, slow tasteful reveals, serif pairings.

### restaurant / wellness / portfolio / agency / gaming / music / cinematic
- Use the **local DNA library first** (it's strong on these verticals), and pull
  current-year polish from Awwwards/Godly in that category. Global bars:
  agencies (Active Theory, Locomotive, Cuberto), gaming (Riot, PlayStation),

## Using a benchmark in a build (the recipe)

1. Pick the local reference(s) from `index.json` + read their **DNA** (the legal,
   concrete extraction source).
2. Name **1–2 web benchmarks** from this file (or a fresh current-year search)
   that match the vertical/mood — e.g. "CTA + trust cards like **Xendit**, motion
   like **Linear**".
3. In the proof block (doctrine §7), state what you're taking from the web
   benchmark as a **pattern** ("pill CTA with soft shadow + hover-lift, à la
   Stripe"), adapted to the user's palette — not a copied asset.
4. Build: local DNA gives the concrete classes/keyframes; the web benchmark
   raises the bar on component polish & CTA feel. Re-skin everything to the
   user's brand.

If offline or search fails, this file alone is enough — the named benchmarks give
Sonnet a concrete taste bar without a live fetch.
